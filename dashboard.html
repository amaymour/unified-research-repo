MCP Server Configuration

Add this snippet to your Claude Code configuration (~/.claude.json) to connect the research workflow as an MCP tool:

{
  "mcpServers": {
    "research-workflow": {
      "command": "python3",
      "args": ["/root/unified-research-repo/mcp_server.py"]
    }
  }
}
